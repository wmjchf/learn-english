## 1. 仓库结构

```
app-starter/
├── app/                 # Flutter iOS/Android
├── backend/             # Express + MySQL
├── docs/                # PRD / 技术文档
└── .cursor/rules/       # Agent 约定
```

## 2. 运行时

| 组件 | 技术 | 默认 |
| --- | --- | --- |
| App | Flutter 3.x / Dart `^3.12` | `ApiConfig` → `http://127.0.0.1:3001` |
| Backend | Node 23.6.0、pnpm、Express 5、mysql2 | `0.0.0.0:3001` |

认证：手机号短信验证码 → JWT access + refresh（`user_sessions`）。开发模式 `SMS_DEV_MODE=true` 时验证码固定为 `SMS_DEV_CODE`（默认 `123456`）。

## 3. 已有 API

| 路径 | 说明 |
| --- | --- |
| `GET /api/health` | 健康检查 |
| `POST /api/auth/sms/send` | 发验证码 |
| `POST /api/auth/sms/login` | 登录 |
| `POST /api/auth/refresh` | 刷新 token |
| `GET /api/auth/me` | 当前用户 |
| `DELETE /api/auth/account` | 注销 |

## 4. 数据库

- `pnpm db:init` 建库
- `pnpm db:migrate` 执行 `sql/001_schema.sql`（users / user_sessions / sms_send_logs）
